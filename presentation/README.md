# Презентация «Студенческий подряд» (8 слайдов)

Редактируемый PPTX, собранный программно (python-pptx). Дизайн реконструирован по
текстовому ТЗ и стилистике текущей версии презентации; текст — строго по ТЗ.

Файлы:

- `stud_podryad_deck.pptx` — итоговая презентация (16:9, 13.333×7.5 in, 8 слайдов).
- `build_deck.py` — сборка слайдов (весь текст и геометрия правятся здесь).
- `ppt_helpers.py` — палитра, хелперы форм, навигация по критериям, донат-диаграммы, QR.
- `render_check.py` — контрольный рендер PPTX→PNG + проверки (переполнения текста,
  вылеты за границы слайда). Запуск: `python render_check.py stud_podryad_deck.pptx render`.
- `assets/` — изображения: кройки интерфейса портала из реальных ассетов сайта
  (`ui_home.png`, `ui_catalog.png`, `ui_task.png`), фото В. Путина (РИА Новости,
  заседание Госсовета 25.12.2025), QR-коды.

Пересборка:

```bash
python build_deck.py && python render_check.py stud_podryad_deck.pptx render
```
